## Estrutura

```
/
├─node_modules/ 		# pacotes
├─public/				# arquivos estáticos
├─src/					# diretório principal do projeto
│	├── components			 	
│	├── contexts
│	├── hooks
│	├── integrations
│	├── lib
│	├── pages
├─supabase/				# diretório do banco de dados
├─.gitignore			
├─bun.lockb
├─components.json
├─eslint.config.js
├─index.html
├─package.json
├─package.json
├─postcss.config.js
├─README.md
├─tailwind.config.ts
├─tsconfig.app.json
├─tsconfig.json

```
